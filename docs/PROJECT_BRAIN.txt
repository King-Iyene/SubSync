1. WHAT IT IS
SubSync is a GoHighLevel (GHL) Marketplace app for appointment-driven agencies (home services, med spas, solar, real estate, coaches). Positioning: "Know what is happening in every client account before your client does." It watches outcomes (leads never answered, unmarked appointments, SLA breaches, stale deals), sends alerts, and gives shareable audits and weekly digests. It is alerts-first and action-first, not another reporting tool. One app, two views: agency view (all client accounts) and account view (one business). Identity comes from GHL SSO in the iframe. Public wording: say "client accounts", never vendor words in the UI.

2. WHY THIS LANE (from research, see docs/COMPETITORS.md, docs/reference/)
- Biggest marketplace player All The Apps: about 196.6K installs, 4.7 stars from 61 reviews, $129 / $299 / $499 per month. Owns white-label, onboarding, support desk, integrations, a multi-location dashboard builder. Does not visibly track show rate, speed to lead, setter performance. Weak points: complexity (1,315 features), 165 permission scopes, high entry price.
- GHL native reports cover appointments, agent performance, pipeline per account, with limited history; reviewers say "wide rather than deep".
- Client reporting is a commodity (AgencyAnalytics about $12 to $15 per client, Two Minute Reports, Looker Studio, Databox).
- Our wedge: alerts and queues (push, not pull), our own event history (stage and status changes, appointment outcomes), cross-account setter and closer visibility, speed to value (Instant Audit), few permissions, focus on 8 to 12 outcomes done deeply.
- Mistakes not to repeat: All The Apps is paid; GHL has native reports; "nobody does cross-account" was overstated; feature count is a weakness.

4. NON-NEGOTIABLE RULES
- Tenant isolation: a client account never sees another's data; an agency never sees another agency's. Enforced server side from the verified SSO payload. Cross-tenant tests (check-tenancy) run alone before every push to main and must print "nothing changed: ok".
- All CRM writes go through the safe write gateway: preview first, typed confirmation for delete, dry-run unless WRITE_GHL_LIVE and the per-account opt-in are on. All sends go through gated transports (SEND_EMAIL_LIVE, SEND_SLACK_LIVE).
- Additive migrations only. Feature flag every module. Idempotent webhooks and sync. Every metric has one written definition in docs/METRICS.md.
- Design for millions of leads and 100 to 200 client accounts: SQL aggregates, server paging (20/50/100), never load all rows.
- White-label safe: SubSync logo by default, agency brand only when white-label is on; no vendor words in UI or emails.

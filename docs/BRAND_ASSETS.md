# Brand marks for connected tools

Shown as inline SVG (src/lib/brand-marks.ts, drawn by src/app/app/ds/brand-icon.tsx). Files in public/brand/tools/. Never hotlinked, never redrawn.

| Tool | Source |
|---|---|
| Slack | The 2019 hash mark as published on Wikimedia Commons (Slack_icon_2019.svg), original brand colours. |
| Fathom | The logo mark file served by fathom.video (logotype-new.svg), original colours. |
| Zoom, Google Meet, Google Calendar, Gmail | simple-icons 16.37.0 (CC0 for the files; the marks stay the property of their owners). Filled with the brand colour from that package. |

Marks sit on a light tile in light and dark pages, so the brand colours stay correct in both. No CRM vendor logo is used anywhere.
Check the official press kits before a public launch.
